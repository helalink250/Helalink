Helalink Rwanda Landing Page + Links - Quick Setup
=======================================

Files included:
- index.html -> Landing page with WhatsApp and Registration buttons
- links.html -> Link hub for WhatsApp, registration, Telegram, Instagram, TikTok
- README.txt -> Hosting instructions

How to host:
1. Open index.html locally to test.
2. Upload both files to Netlify: https://app.netlify.com/drop
3. Or upload to GitHub Pages (both files in the same repo)
